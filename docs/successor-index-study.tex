\begin{abstract}
The \texttt{pddl\_fol} planner initially used breadth-first search and evaluated
every grounded action in every state. We study an index that selects actions
using a necessary positive precondition atom while leaving full first-order
formula evaluation unchanged. On IPC 1998 Gripper 1, median process time falls
from 107.1 to 13.2 ms (8.14$\times$); on two generated Gripper problems with 7
and 8 balls, the improvement reaches 12.13$\times$ and 13.80$\times$. Plans
and explored-state counts match the baseline. We then add A* with admissible
delete-relaxation and goal-cover lower bounds. On a synthetic problem with 12
independent inspections, A* reduces expanded states from 4096 to 13 and median
time from 64.3 to 2.31 ms compared with BFS in the same revision. A* is slower
on the measured Gripper problems because heuristic evaluation costs more than
the reduction in expansions saves. All compared plans have the same optimal
length. These results are specific to the tested instances and do not establish
general competitiveness.
\end{abstract}

\section{Motivation and Related Work}
PDDL describes action schemas with variables and first-order formulas. Many
planners ground actions before search. Corr\^ea et al.~\cite{correa2020}
interpret lifted successor generation as query evaluation over a state and
study database optimizations. Lifted heuristics based on delete relaxation and
FF were proposed later~\cite{correa2021,correa2022}. Fast Downward uses a
representation and successor generators that differ from this project
~\cite{helmert2006}. The $h_{\max}$ bound follows Bonet and
Geffner~\cite{bonet2001}; the course notes cover relaxations, A*, and
admissibility~\cite{manciniB2,manciniA3}.

The first part of this study addresses a narrow bottleneck: scanning every
already-grounded action at each expansion. The second adds A* and two admissible
lower bounds. Treating applicability as a query motivates the index, but the
planner remains fully grounded in this report; it introduces neither an
external FOL solver nor lifted search.

\section{Index and Correctness}
Let $A$ be the sequence of grounded actions and $s$ the set of atoms
true in the state. For each action $a$, we seek a positive atom $r(a)$
that must be true whenever its precondition $\varphi_a$ is true. The
search traverses only atom and conjunction nodes; among candidates, it
chooses an atom of maximum arity. Subtrees containing disjunctions,
negations, implications, or quantifiers provide no constraints for this
index. An action with no necessary positive atom is placed in the
unfiltered set $U$.

Before search, we build $I_p=\{a\in A:r(a)=p\}$.
For each state, we evaluate only
\begin{equation}
 C(s)=U\cup\bigcup_{p\in s} I_p.
\end{equation}
We order $C(s)$ according to the original order in $A$, then evaluate
the full precondition for each candidate. If $a$ is applicable,
$\varphi_a(s)$ is true; by construction, $r(a)$ is true in $s$, or
$a\in U$. Therefore $a\in C(s)$: no applicable action is omitted.
Breadth-first search order and tie-breaking remain unchanged. The index
requires additional memory proportional to $|A|$; grounding cost is
unchanged.

\section{Experimental Protocol}
We compare initial commit \texttt{1487d5c} with the indexed branch,
both compiled using \texttt{cargo build --release} and Rust 1.92.0.
Machine: AMD Ryzen 5 7640U, Linux 7.2.5, 12 logical CPUs. Each measurement
uses \texttt{time.perf\_counter} around the full CLI process, including
startup, parsing, grounding, and search. Runs of the two versions are
interleaved; we report the median of 20 pairs for IPC instances and 3 pairs
for the two generated problems. Search limit: \texttt{--max-states 100000}.
CPU frequency was not controlled; short runtimes, especially Blocks, are
sensitive to noise.

The Gripper 1 (IPC 1998) and typed Blocks 4-0 (IPC 2000) domain and
problem files come from the public \texttt{pddl-instances} corpus,
revision \texttt{cf19edf7}~\cite{pddlinstances}. The repository files
\path{benchmarks/gripper-7.pddl} and \path{benchmarks/gripper-8.pddl}
extend the same domain to 7 and 8 balls; they are \emph{not} official IPC
instances. For every row, the baseline and indexed versions produce
identical CLI output, including the plan and number of explored states.

\section{A* Search with Admissible Lower Bounds}
For goals that are conjunctions of positive ground atoms $G$, the heuristic
combines two lower bounds. For each state $s$, $h_{\max}(s)$ assigns cost
zero to atoms already true. Ignoring delete effects, a grounded action assigns
each added effect the relaxed cost
\[
  1+\max_{p\in P^+(a)} c_s(p),
\]
where the maximum of an empty set is zero and $P^+(a)$ contains only positive
atoms recognized as necessary in the precondition. Unsupported precondition
subtrees, including disjunctions, negations, implications, and quantifiers,
add no relaxed prerequisites; the complete formula is still checked before
any actual transition. Costs are propagated to a fixed point, and the maximum
cost among goal atoms gives $h_{\max}$. Ignoring constraints and deletes can
only shorten the relaxed plan, so this value does not overestimate the real
distance. A goal atom unreachable in the relaxation identifies a safe dead end.

The second bound estimates goal coverage. Let $m(s)=|G\setminus s|$ and let
$k$ be the maximum number of distinct goal atoms one grounded action can add.
If $m(s)>0$ and $k=0$, the goal is unreachable; otherwise,
\[
  h_{\mathrm{cover}}(s)=\left\lceil\frac{m(s)}{k}\right\rceil.
\]
Each action can make at most $k$ missing goal atoms true, so this bound is
admissible and consistent. We use
$h(s)=\max(h_{\max}(s),h_{\mathrm{cover}}(s))$, which preserves both
properties. For other FOL goal forms, the heuristic is zero. A* uses unit
costs, retains the lowest known path cost for each state, reopens a state when
a cheaper path is found, tests goals when removing states from the frontier,
and replays a solution before returning it.

\subsection{Additional Experiments}
We compare three configurations: indexed BFS at commit \texttt{82f6524}, and
BFS/A* at the pre-lift Agent integration commit \texttt{ee51799}. The
synthetic benchmark \texttt{benchmarks/independent-inspections-12.fol} has 12
independent goals, each achieved by one \texttt{inspect} action; it is not an
IPC instance. We use the same Gripper domain from revision \texttt{cf19edf7}
of the corpus above and the same Gripper 1, 7, and 8 problems. Builds use Rust
1.92.0 and \texttt{cargo build --release} on an AMD Ryzen 5 7640U running
Linux. End-to-end time includes process startup, parsing, grounding, search,
and CLI output. After one warm-up per configuration, run order is alternated.
We report medians of 10 runs for inspections and Gripper 1, 7 runs for Gripper
7, and 5 runs for Gripper 8. Raw data are in
\texttt{benchmarks/search-results.csv}. CPU frequency and system load were not
controlled.

The independent inspections favor the goal-cover bound: $h_{\max}$ sees a
one-step relaxed cost for each goal, while $h_{\mathrm{cover}}$ captures the
12 distinct actions required. A* expands about 315 times fewer states than
BFS and is about 28 times faster in the same revision. On Gripper, expanded
states fall only slightly because the relaxation underestimates the capacity
constraints of the two grippers and repeated transport between rooms. A* is
therefore about 1.7--1.8 times slower than Agent BFS on these instances. This
negative result shows that an admissible heuristic is not necessarily a runtime
improvement. All configurations return plans of the same optimal length;
individual action sequences may differ because of tie-breaking.

\section{Limitations and Conclusion}
The evaluation covers two domains and a small number of problems on one
machine. The larger Gripper instances are generated; they do not replace a full
IPC suite or a timeout-based coverage comparison. The planner still faces the
grounding challenge discussed by Corr\^ea et al.~\cite{correa2020}. Formulas
without usable positive precondition atoms require bounded Cartesian fallback.
The index gives a local, measurable, and semantically conservative improvement;
the heuristic helps substantially on the synthetic independent-goal problem
but slows the measured Gripper cases. Neither result establishes general
competitiveness with mature planners. Future work should estimate shared
resource constraints without paying the full relaxation cost at every state.
